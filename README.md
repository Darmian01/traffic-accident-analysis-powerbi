# 🚗 Road Safety & Traffic Crash Analytics

## 📌 Project Overview
This project provides an end-to-end data analysis of road traffic crash patterns, casualty severity, and primary cause indicators across various states. The goal is to deliver actionable insights that can drive data-backed road safety interventions, optimize emergency response allocation, and support policy-making for safer infrastructure.

---

## 🎯 Key Objectives
* **Identify Crash Hotspots:** Pinpoint geographical regions and states with the highest frequency and severity of traffic accidents.
* **Analyze Casualty Patterns:** Quantify fatal, serious, and minor injuries across different demographics and road types.
* **Determine Primary Causes:** Evaluate driver behavior, environmental conditions, and mechanical failures contributing to collisions.
* **Inform Safety Interventions:** Present clear data visualizations and recommendations for transport authorities and public safety planners.

---

## 🛠️ Tech Stack & Tools
* **Data Processing & Cleaning:** Python (Pandas, NumPy) / Excel
* **Database Management:** MySQL
* **Business Intelligence & Visualization:** Power BI
* **Documentation & Version Control:** Git, GitHub

## 💡 Recommended Interventions
1. **Targeted Law Enforcement:** Deploy increased patrol monitoring along identified high-crash routes during peak accident hours.
2. **Infrastructure Upgrades:** Prioritize road maintenance, lighting, and signage in states with top casualty density.
3. **Public Safety Campaigns:** Launch localized awareness campaigns addressing primary causes such as speeding and dangerous overtaking.
